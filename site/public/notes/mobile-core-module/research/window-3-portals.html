Виджет, который один модуль даёт, а другие встраивают — без знания, откуда внутри модуля берётся картинка, стейт или источник. Типизированный <Portal<…Props> … />.

Иконка приложения — портал с инкапсулированным источником

Кто даёт портал: модуль application (контейнер application-icon). Кто встраивает: модули header, notifications, menu и т. д. Главное: источник иконки (CDN / Remote Config) спрятан внутри application.
application · containers/application-icon/index.tsx
import { LayerProps, Portal, withLayer } from '@core'; import { ApplicationStore } from '../../model'; interface Props extends LayerProps<ApplicationIcon.Props> {} export class ApplicationIcon extends PureComponent<Props> { private _store = new ApplicationStore(); override render() { const { scheme, size } = this.props.layer.props; const source = this._store.getIconSource(scheme); return <Image source={source} size={size} />; } } export namespace ApplicationIcon { export interface Props extends Portal.Props { scheme: 'main' | 'notification' | 'bonus'; size: number; } }
