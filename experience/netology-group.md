# Нетология-групп / Фоксфорд
**03/2014 - 10/2018**
**Технический директор Нетологии**

- Управление несколькими кросс-функциональными командами разработки (в состав каждой команды входили бэк, фронт, мобилки, тестирование, дизайн, devops) - от 15 до 20 человек в подчинении
- Выстраивание процессов разработки
- Найм, перф-ревью, код-ревью
- Архитектура и менторство для backend / frontend / devops команд

## О компании

Продуктовая компания, специализирующаяся на онлайн-образовании полного цикла

- Много технологически сложных сервисов со своей спецификой
  - система трансляций на Erlang,
  - Heavy-SQL based решения c большой интерактивностью и нагрузкой (огромные реляционные БД)
  - песочницы для кода и тренажеры по программированию (когда docker только становился mainstream)
  - веб-редакторы для медиа-контента, конструкторы лендингов
  - encrypted-хранилища для документов
  - кастомные ETL-решения
- Сильная команда разработки, которая способствовала взаимному развитию и обучению
- Флагман онлайн-образования в России в тот период (в настоящий момент также заметна)

## Что я сделал

Пришел в компанию как ведущий разработчик (бэкенд, rails-стэк), стал тимлидом, затем архитектором, после этого CTO

- Выстроил процесс разработки с нуля, занимался наймом и обучением - проведено более 200 интервью (в среднем по 3-5 интервью в неделю в период активного найма)
- Организовал более 20 мероприятий для разработки (техно-пятницы, митапы, совместные обучения на курсах, тренинги по процесса разработки)
- Занимался бюджетированием, P&L, проектированием инфры (закупки серверов, аренда сервисов, оптимизации расходов - смена платформ, съезжали с Microsoft Azure на Google Cloud и self-hosted решения)
- Положил начало DevOPS культуре в Нетологии. Автоматизировал деплой, мною выстроена стейджинг/препрод инфра (ansible, docker-compose, тогда еще не было k9s)
- Мной разработана и реализована стратегия миграции Нетологии на новую платформу (от монолитов к микро-сервисам).
  Я руководил распиливанием и миграцией приложений на каждом этапе плана, часть сервисов реализовывал самостоятельно.
- Реализовывал критический для компании функционал в качестве архитектора (оплаты, мониторинг и хелсчеки, движок курсов)
- Сформирован сплоченный коллектив

## Интересное

- получен огромный управленческий и технический опыт
- большинство проектов компании - high-load c большим количеством операций на запись (классический highload больше про чтение)
